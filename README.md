# Dashboard de Indicadores — Power BI
[![Power BI](https://img.shields.io/badge/Power_BI-F2C811?style=for-the-badge&logo=powerbi&logoColor=black)](https://powerbi.microsoft.com/)

Um painel interativo desenvolvido em Power BI para análise de indicadores de desempenho, focado em transformar dados brutos em insights visuais claros e estratégicos.

## Funcionalidades
- Visualização dinâmica de KPIs e métricas principais de desempenho
- Filtros e segmentações de dados interativos para análise cruzada
- Gráficos modernos estruturados para facilitar a tomada de decisões
- Tratamento e modelagem de dados utilizando DAX e Power Query

## Como visualizar / Testar
Como este projeto foi estruturado para visualização no Power BI Desktop:
1. Baixe o arquivo do projeto (`.pbix`) diretamente deste repositório.
2. Certifique-se de ter o **Power BI Desktop** instalado em seu computador (disponível gratuitamente).
3. Abra o arquivo baixado para interagir com os filtros, relatórios e gráficos.

## Tecnologias e Ferramentas
- **Power BI Desktop** (Criação de relatórios e painéis)
- **DAX & Power Query** (Fórmulas, cálculos e tratamento de dados)
- **Microsoft Excel** (Base de dados estruturada)
